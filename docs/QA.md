# Проверки версии 2.1

11 автоматических проверок прошли. Проверяются простой JSON, оба пустых состояния продуктов, доступность, поиск без паролей, фильтры, сохранность данных, JSON и равнозначный офлайн-слепок, экранирование строк, отсутствие авторизации и endpoint-ов сессии, праздничные PNG и их очистка.

Все 50 клиентов проверены: 38 доступны, 3 альтернативных пароля сохранены. Новый рабочий JSON скопирован без изменения значений. Банковская доступность учётки отличается от удалённой авторизации сайта и продолжает работать как раньше.

Ручная приёмка:

1. Открыть dist/index.html или «Открыть сайт.cmd»: каталог загружается сразу, без входа.
2. npm start → /preview/project/: данные доступны без cookie и без пользовательской сессии.
3. Проверить 50 карточек, поиск по ФИО/login/ID, фильтры и «Все», сетку 3/4.
4. Проверить копирование логина, ID, обычных и альтернативных паролей, ручной вариант буфера.
5. Проверить пустые/ошибочные данные в тестовой копии; после исправления повторить сборку.
6. Добавить объект в src/data/test_clients_simple.json, пересобрать и проверить новую запись.
7. Проверить мобильный экран, клавиатуру и кнопку «Тест завершен».

Прямой file:// недоступен в браузерной среде автоматизации; равенство и исполнимость офлайн-слепка проверены автоматически. Развёртывание в корпоративном GitLab в этой поставке не запускалось.

В браузере подтверждено: каталог открывается сам, 50 карточек, формы входа и кнопки выхода нет. Фильтр просрочки даёт 3 записи, «Все» возвращает 50, копирование логина работает.
