# Техническое задание · версия 2.1

Статический русскоязычный каталог тестовых клиентов. Авторизация и защищённый backend версии 2.0 отменены по прямому запросу пользователя. Каталог открывается сразу при загрузке, без входа. Сохранён экран «Главная» через боковое меню.

Данные: src/data/test_clients_simple.json, корень clients, поля name/login/password/id/products/available, необязательные access_note/other_passwords/no_products. Публичный комплект содержит вымышленные записи. Копирование объекта добавляет клиента без изменения кода; для локального просмотра достаточно обновить страницу.

Сайт читает один JSON по относительному адресу. Локально файл отдаёт сервер предпросмотра на localhost. При сборке копия JSON попадает в dist, который можно разместить в подпути проекта. Посетитель может скачать JSON целиком.

Карточки: ФИО, единый логин, открытый пароль, ID, альтернативы. Описание — блок продуктов через « · ». Нет отдельного телефона и дублирующей нижней строки описания. Пустой массив с no_products true — «Продуктов нет», иначе «Нет данных о продуктах». Мягкие цвета меток сохраняются.

Сохранены проверка структуры, ошибки без значений, загрузка/пустая выдача, поиск, OR/AND-фильтры, доступность из available/реквизитов/access_note, недоступные внизу, сетка 3/4, адаптивность, копирование, коты и праздничные PNG. Сессий, входа, выхода и пользовательского пароля каталога нет.
