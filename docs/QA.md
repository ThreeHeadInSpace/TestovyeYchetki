# Проверки каталога

Выполните `npm run check:data`, `npm test` и `npm run build`.

1. Запустите `npm start` и откройте путь `/preview/project/`. Каталог загружается сразу.
2. Проверьте поиск по ФИО, логину и ID, фильтры, сброс, переключение сетки 3/4 и мобильную вёрстку.
3. Проверьте копирование полей и предупреждение недоступной учётки. Проверьте, что **Copy full** копирует четыре строки в нужном порядке, включая пустые строки для пропущенных полей, и исключает альтернативные пароли.
4. Добавьте запись в исходный JSON и обновите локальную страницу. После новой сборки проверьте её в опубликованной версии.
5. Проверьте анимацию кнопки «Тест завершен».

В `dist/data` после сборки должен быть только `test_clients_simple.json`. Он совпадает с исходным файлом побайтно.
